1
position: relative ▶
Теорія

За замовчуванням кожен елемент має position: static — він просто стоїть у потоці документа.

position: relative дає дві речі:

  • Зміщення через top/left/right/bottom.
  • Стає точкою відліку для вкладених absolute-елементів.
Що зробити

Додай до блоку .hero-section:

.hero-section {
  position: relative;
}
Що спостерігати

Видимих змін майже немає — але hero тепер є точкою відліку для завдання 2.

Подумай
  • Навіщо relative, якщо нічого не змінилось?
2
position: absolute ▶
Теорія

position: absolute виймає елемент з потоку. Він позиціонується відносно найближчого предка з position (не static).

Решта елементів «не бачать» absolute-елемент — він для них ніби зник.

Що зробити
.breaking-badge {
  position: absolute;
  top: 20px;
  left: 20px;
}
Що спостерігати

«BREAKING» переїхав у верхній лівий кут hero — як на справжніх новинних сайтах!

Подумай
  • Відносно чого позиціонується badge? Чому?
  • Видали position: relative з hero — що зміниться?
3
position: fixed ▶
Теорія

position: fixed фіксує елемент відносно вікна браузера. При прокрутці він не рухається.

Що зробити
.site-header {
  position: fixed;
  top: 0;
  width: 100%;
}
Що спостерігати

Прокрути preview — шапка залишається нагорі. padding-top: 80px на body вже є в базових стилях.

Подумай
  • Де ще зустрічається fixed? (2–3 приклади)
  • Навіщо padding-top на body?
4
position: sticky ▶
Теорія

Гібрид relative і fixed. Елемент рухається зі сторінкою, але при досягненні порогу — «прилипає».

Що зробити
.sidebar {
  position: sticky;
  top: 80px;
}
Що спостерігати

Прокрути — sidebar зупиняється під шапкою і залишається видимим.

Подумай
  • Чому top: 80px, а не top: 0?
5
z-index ▶
Теорія

z-index — «висота» елемента над сторінкою. Більше число — вище.

Працює лише на позиціонованих елементах (не static).

Що зробити

Додай до існуючого блоку .site-header або створи новий:

.site-header {
  z-index: 100;
}
Що спостерігати

Шапка тепер перекриває червоний alert «🔴 В ПРЯМОМУ ЕФІРІ».

Подумай
  • Що буде при z-index: 1? Спробуй.
  • Чому z-index не працює на static?
6
display: inline ▶
Теорія

Елемент поводиться як слово в тексті: не починає новий рядок, ширину/висоту задати не можна.

За замовчуванням inline: <a>, <span>, <strong>.

Що зробити
.topic-chip {
  display: inline;
}
Що спостерігати

Теги (AI, Роботика...) тепер в один рядок.

Подумай
  • Чому теги були у стовпчик? (<div> — block)
  • Спробуй задати width: 200px — що станеться?
7
display: block ▶
Теорія

Елемент займає весь рядок і починає з нового. Можна задавати width, height, padding, margin.

Що зробити
.footer-link {
  display: block;
  padding: 6px 0;
}
Що спостерігати

Посилання у футері тепер у стовпчик — кожне на своєму рядку.

Подумай
  • Чому <a> за замовчуванням inline?
  • Яка перевага block для посилань меню? (Підказка: зона кліку.)
8
display: inline-block ▶
Теорія

Гібрид: елементи стоять в рядок (як inline), але можна задати width/height (як block).

Що зробити
.stat-box {
  display: inline-block;
  width: 180px;
  vertical-align: top;
  margin-right: 8px;
  margin-bottom: 0;
}
Що спостерігати

Три блоки статистики (1.2M / 48K / 9K) тепер стоять поряд.

Подумай
  • Чим inline-block відрізняється від inline?
  • Спробуй прибрати vertical-align: top.
