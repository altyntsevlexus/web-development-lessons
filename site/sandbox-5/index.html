1
height & width ▶
Теорія

width і height задають розмір вмісту елемента. Пікселі дають точний фіксований розмір.

width: 100% означає «займи всю ширину батьківського елемента».

Що зробити

Збільш банер-герой до 400px:

.hero-banner {
  height: 400px;
}
Що спостерігати

Космічний банер стає великим і ефектним.

Подумай
  • Що станеться, якщо прибрати height зовсім?
  • Що означає height: 50%?
2
border ▶
Теорія

border малює лінію навколо елемента. Потрібні три значення: ширина стиль колір.

Стилі: solid, dashed, dotted.

Що зробити
.article-preview {
  border: 2px solid #0f3460;
}
Що спостерігати

Картка статті отримує видиму рамку — більше не «біле на білому».

Подумай
  • Спробуй змінити solid на dashed.
  • Що станеться без слова solid?
3
border-radius ▶
Теорія

border-radius закруглює кути. Значення 50% на квадраті робить коло.

Що зробити

Частина А — закруглити кути картки:

.article-preview {
  border-radius: 8px;
}

Частина Б — аватар колом:

.author-avatar {
  border-radius: 50%;
}
Що спостерігати

Картка з м'якими кутами; аватар-коло замість квадрата.

Подумай
  • Спробуй border-radius: 24px на картці.
  • Чому 50% дає коло лише на квадраті?
4
padding ▶
Теорія

Padding — простір всередині елемента між вмістом і рамкою.

Скорочений запис: padding: top right bottom left (за годинниковою стрілкою).

Що зробити
.article-preview {
  padding: 20px;
}
.fact-card {
  padding: 16px 20px;
}
Що спостерігати

Текст у картках більше не впирається в краї.

Подумай
  • Що означає padding: 16px 20px? (два значення)
  • Padding — всередині рамки чи зовні?
5
margin ▶
Теорія

Margin — простір зовні елемента. margin: 0 auto центрує блок горизонтально (потрібна явна width).

5а — відступи між абзацами
.article-body p {
  margin-top: 24px;
}
5б — центрування через auto
.newsletter-banner {
  margin: 0 auto 32px;
  padding: 14px 24px;
}
.container {
  max-width: 960px;
  margin: 0 auto;
}
Що спостерігати

Абзаци розділяються; банер і весь вміст — по центру.

Подумай
  • Чому margin: auto не спрацює без width?
  • Вертикальні margin зливаються — горизонтальні ні. Чому?
6
min / max ▶
Теорія

max-width / min-height задають межі: елемент адаптується, але не виходить за них.

Що зробити
.featured-quote {
  max-width: 680px;
  min-height: 80px;
}
Що спостерігати

Цитата зручно читається на будь-якій ширині екрана.

Подумай
  • Чим max-width: 680px відрізняється від width: 680px?
  • Спробуй max-height: 60px — що станеться з текстом?
7
overflow ▶
Теорія

Коли вміст більший за контейнер, overflow вирішує що робити: visible (вилазить), hidden (обрізати), scroll (прокручувати).

Що зробити
.mission-log {
  overflow: scroll;
}
Що спостерігати

Журнал місії тепер прокручується — весь текст доступний.

Подумай
  • Спробуй overflow: hidden — що змінилось?
  • Коли краще hidden, а коли scroll?
8
CSS reset ▶
Теорія

Браузери додають стандартні margin і padding до елементів. Розробники скидають їх на початку CSS, щоб почати з чистого аркуша.

Що зробити
* {
  margin: 0;
  padding: 0;
}
Що спостерігати

Стандартні відступи браузера зникають. Твої явні правила залишаються — вони конкретніші.

Подумай
  • Чому 0 не потребує одиниці виміру (px)?
  • Чому наші margin-top: 24px на абзацах не зникли?
9
visibility ▶
Теорія

visibility: hidden — елемент невидимий, але місце в макеті залишається.

display: none — елемент повністю зникає, місця не займає.

Що зробити
.nav-item--soon {
  visibility: hidden;
}
Що спостерігати

«Premium» зникає, але порожнє місце залишається в навігації.

Подумай
  • Заміни на display: none — що змінилось?
  • Коли потрібен visibility: hidden замість display: none?
