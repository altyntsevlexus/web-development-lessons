1
* — всі елементи ▶
Теорія

Браузер додає власні відступи до елементів. Скидання починається з * { margin: 0; padding: 0; }.

* — універсальний селектор. Вибирає кожен елемент на сторінці. Специфічність = 0 — будь-яке інше правило перевизначить його.

Що зробити
* {
  margin: 0;
  padding: 0;
}
Що спостерігати

Білі поля навколо сторінки зникають — відступи скинуто.

Подумай
  • Чому специфічність * = 0? Що це означає на практиці?
2
тег — всі h2 ▶
Теорія

Назва HTML-тегу без дужок — вибирає всі елементи з цим тегом на сторінці.

Що зробити
h2 {
  color: #0f3460;
}
Що спостерігати

Всі заголовки h2 стали темно-синіми — і в article, і в aside.

Подумай
  • Як зробити, щоб тільки один h2 мав інший колір? (→ клас або ID)
3
#id — унікальний елемент ▶
Теорія

# перед назвою ID вибирає один конкретний елемент. ID має бути унікальним на сторінці.

Специфічність: #site-title (100) > .header-title (10) > h1 (1).

Що зробити
#site-title {
  font-size: 2.5rem;
  color: #e94560;
}
Що спостерігати

Назва блогу «GameZone Blog» стала великою та яскраво-червоною.

Подумай
  • Чому не можна давати двом елементам однаковий ID?
4
.клас — повторювані елементи ▶
Теорія

. перед назвою класу. Один клас — стиль застосовується до всіх елементів з ним.

Що зробити
.game-tag {
  background-color: #e94560;
  color: white;
  padding: 4px 12px;
  border-radius: 20px;
  font-size: 0.8rem;
}
Що спостерігати

Всі бейджики-теги (Action, RPG, Indie...) перетворились на яскраві таблетки.

Подумай
  • Що якби кожен тег мав окремий ID — скільки правил довелося б писати?
5
:hover — стан при наведенні ▶
Теорія

:hover — псевдоклас. Застосовується коли курсор на елементі. Записується через двокрапку.

Що зробити
a:hover {
  color: #e94560;
  text-decoration: none;
}
Що спостерігати

Наведи курсор на посилання в sidebar — вони змінюють колір на червоний.

Подумай
  • Ще псевдокласи: :focus, :active, :first-child. Що вони роблять?
6
h2.featured — ланцюжок ▶
Теорія

Без пробілу між двома селекторами — елемент повинен відповідати обом одночасно.

h2.featured ≠ .featured — перший вибирає лише h2 з класом featured.

Що зробити
h2.featured {
  color: #e94560;
  font-style: italic;
}
Що спостерігати

Тільки перший заголовок «Топ-ігри місяця» змінив колір — він один має клас featured.

Подумай
  • Специфічність h2.featured = 1 (тег) + 10 (клас) = 11. Чи переможе воно правило завдання 2?
7
nav a — вкладений елемент ▶
Теорія

Пробіл між селекторами — другий елемент знаходиться всередині першого (на будь-якій глибині).

Що зробити
nav.site-nav a {
  text-decoration: none;
  color: #e0e0e0;
  padding: 0 12px;
}
Що спостерігати

Посилання в навігації більше не підкреслені і мають рівні відступи. Посилання в sidebar не змінились.

Подумай
  • Чому nav.site-nav a не вплинуло на посилання в <aside>?
8
h1, h2, h3 — групування ▶
Теорія

Кома між селекторами — одне правило для кількох елементів одночасно. Просто скорочення: замість трьох правил — одне.

Що зробити
h1,
h2,
h3 {
  font-family: Georgia, serif;
}
Що спостерігати

Всі заголовки змінили шрифт на засічковий Georgia — сайт виглядає по-іншому.

Подумай
  • Чи можна об'єднати в групу будь-які селектори, навіть класи і ID разом?
9
Специфічність ▶
Теорія

Коли кілька правил суперечать — перемагає те, що має вищу специфічність.

  • * = 0
  • тег = 1
  • .клас, :hover = 10
  • #id = 100
Що зробити

Додай ці правила по черзі і спостерігай, який колір перемагає:

h1             { color: green; }
.header-title  { color: orange; }
#site-title    { color: purple; }
Що спостерігати

Заголовок стане фіолетовим — #site-title (100) перемагає клас (10) і тег (1).

Подумай
  • Як можна «змусити» правило з нижчою специфічністю перемогти? (Підказка: !important)
