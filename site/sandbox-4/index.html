1
font-family ▶
Теорія

Змінює шрифт тексту. Якщо назва складається з кількох слів — береться в лапки. Через кому вказується запасний шрифт.

Що зробити
h1, h2 {
  font-family: 'Georgia', serif;
}
Що спостерігати

Заголовки змінили шрифт — виглядають більш елегантно.

Подумай
  • Навіщо запасний шрифт serif? Що буде, якщо Georgia не знайдена?
2
font-size ▶
Теорія

Розмір тексту. px — фіксований розмір. rem — відносно кореневого елемента (1rem = 16px).

Що зробити
.hero-title {
  font-size: 3rem;
}
Що спостерігати

Заголовок у hero-секції став великим і домінує на сторінці.

Подумай
  • Спробуй 4rem або 5rem. Скільки пікселів = 3rem?
3
font-weight ▶
Теорія

Товщина шрифту. bold = 700, normal = 400. Можна числом від 100 до 900.

Що зробити
.nav-link {
  font-weight: bold;
}
Що спостерігати

Посилання в навігації стали жирнішими та помітнішими.

Подумай
  • Яка різниця між font-weight: 400 і font-weight: bold? (Ніякої — bold = 700.)
4
text-align ▶
Теорія

Вирівнювання тексту всередині блокового елемента. Значення: left, center, right, justify.

Що зробити
.hero-overlay {
  text-align: center;
}
Що спостерігати

Текст у hero відцентрований — виглядає як справжній банер.

Подумай
  • text-align центрує текст всередині елемента. Як відцентрувати сам елемент на сторінці?
5
color + background-color ▶
Теорія

color — колір тексту. background-color — колір фону. Кольори: назва, HEX, RGB, RGBA.

Що зробити
.site-header {
  background-color: #1a1a2e;
  color: #ffffff;
}
Що спостерігати

Шапка стала темною зі світлим текстом — сайт набуває характеру.

Подумай
  • Спробуй background-color: rgba(26, 26, 46, 0.9). Що змінилося?
6
opacity ▶
Теорія

Прозорість елемента від 0 (невидимий) до 1 (непрозорий). Впливає на весь елемент разом з вмістом.

Порада: спочатку виконай завдання 7, щоб додати фонове зображення — тоді ефект opacity буде помітний.

Що зробити
.hero-overlay {
  opacity: 0.85;
}
Що спостерігати

Overlay стає напівпрозорим — крізь нього просвічує фонове зображення.

Подумай
  • Різниця між opacity: 0 і display: none? Спробуй 0.3, 0.6, 1.
7
background-image ▶
Теорія

Задає зображення як фон елемента. Завжди разом з background-size і background-position.

Що зробити
.hero {
  background-image: url('https://images.unsplash.com/photo-1511671782779-c97d3d27a1d4?w=1200&q=80');
  background-size: cover;
  background-position: center;
}
Що спостерігати

За текстом hero з'явилося фото концерту — сторінка ожила!

Подумай
  • Різниця між background-size: cover і background-size: contain?
